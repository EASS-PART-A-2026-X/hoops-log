    How to read this page
    • The court is the play. Each pass is a hand-off between the builder, the stat crew (the gate), the reviewer and the GM.
    • Each mark near the top of the key is one gate check on one candidate: a ring passed, a cross failed. The outer ring is the first candidate, inner rings are repairs.
    • The shot clock counts the run's budget down. When it reaches zero the controller kills the running agent.
    • Play-by-play lines with a file name are evidence: click the name to read the saved file. Lines tagged commentary are narration only.
    • The referee blocks edits outside the work order's files. The announcer, referee and gate are plain code, not AI.
    • Only the GM's command approves a run. The buttons on this page display the decision; they do not make it.
